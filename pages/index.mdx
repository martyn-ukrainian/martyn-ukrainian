## 🚀 Learning ML in the open

I'm learning ML with a method I've been building: **Claude Code as mentor + a voice agent right in the terminal for verbal reinforcement after each lesson.** It's not just consuming tutorials — the process itself is the artifact. Roadmap, lessons, spaced retrieval, calibrated knowledge profile — all versioned publicly.

> Explaining out loud catches what reading doesn't. 10 minutes of voice reflection after each lesson turns notes into knowledge.
