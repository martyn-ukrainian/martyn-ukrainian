# Learning ML in public

I'm learning ML engineering out in the open — the roadmap, the lessons, the
reflections, all versioned publicly. This section is the journal.

The core of it: **Claude Code as a mentor, plus a voice agent in the terminal
for verbal reinforcement after each lesson.** Explaining out loud catches what
reading doesn't. → [Read about the method](/learning/method)
