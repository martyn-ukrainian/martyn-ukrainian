# About me

I'm Martyn — a software developer with **9 years** of shipping real products. My
core specialty is **voice AI and realtime telephony**, and I've spent the last
few years building AI/LLM features into production systems. Right now I'm
deliberately widening into **ML engineering**, and doing it in the open.

## What I'm deep in

### 🎙️ Voice AI &amp; realtime telephony — my main area

Years of production experience across multiple voice AI platforms —
multi-provider, multi-tenant, browser-to-phone. I also run my own self-hosted
stack for offline / private inference.

- **Voice frameworks:** Pipecat, LiveKit, Daily.co
- **Telephony:** Twilio, Telnyx, Vonage, Retell AI, Zadarma / SIP
- **STT:** Deepgram, self-hosted Whisper
- **TTS:** Cartesia, ElevenLabs, self-hosted Piper
- **Realtime transport:** WebRTC · WebSocket · SIP

### 🧠 AI / LLM integration

RAG, context engineering, and self-hosted inference — from prototype to shipped
feature. I work across hosted models (Claude, OpenAI, Gemini, OpenRouter) and
self-hosted ones (Ollama, Llama, Whisper, Piper), with pgvector / LangChain /
LlamaIndex for retrieval.

### ⚙️ Product engineering

- **Languages:** TypeScript, JavaScript, Python
- **Backend &amp; realtime:** Node.js, FastAPI, Fastify, Express, Django, WebRTC
- **Frontend:** React, Next.js, Vue (5y in insurance &amp; SaaS), TailwindCSS
- **Databases:** PostgreSQL, MongoDB, Prisma, Redis, Supabase
- **CI/CD &amp; observability:** Docker, GitHub Actions, Vercel, Sentry, PostHog, Langfuse

## Open source

A few things I build and maintain in the open:

- **[voice-agent-skills](https://github.com/martyn-ukrainian/voice-agent-skills)** — Claude Code skills for local, terminal-based voice agents on Pipecat (Deepgram STT → LLM → Cartesia TTS).
- **[termcast](https://github.com/martyn-ukrainian/termcast)** — narrated terminal screencasts written as bash: it types commands like a human and speaks the narration (Piper locally, or Cartesia via API), with a Claude Code skill that scripts a demo from a plain-language topic.
- **[lora-greenhouse](https://github.com/martyn-ukrainian/raspberry-pi-lora-greenhouse-monitoring)** — LoRa greenhouse monitoring on Raspberry Pi: FastAPI + ESP32/C++ firmware + Telegram alerts.
- **[roy](https://github.com/martyn-ukrainian/roy)** — realtime backend + self-hosted ML for autonomous systems.

## What I'm learning

I'm working through a **7-phase ML engineering roadmap** in public — currently in
Phase 2 (classical ML), roughly 40 hours in. The whole process is versioned:

→ [See the roadmap and journal](/learning)

## Why "in public"?

Two reasons. First, explaining out loud catches gaps that silent reading hides —
so I built a method around verbal reflection (more on the
[method page](/learning/method)). Second, an open journal is a better artifact
than a certificate: you can see how I actually think and learn, not just that I
finished something.
